# Online Shop

Учебный pet-проект интернет-магазина: каталог товаров с фильтрацией и сортировкой, JWT-авторизация, личный кабинет, корзина, оформление заказа, избранное и **ролевая модель доступа с полноценной админ-панелью**.

## Стек технологий

**Backend:**
- FastAPI
- SQLAlchemy (SQLite)
- Pydantic — валидация данных
- JWT (python-jose) — авторизация по access/refresh токенам
- bcrypt — хеширование паролей

**Frontend:**
- React + TypeScript
- React Router — маршрутизация между страницами
- react-icons

## Функциональность

**Каталог**
- Список товаров с изображением, названием, ценой и категорией
- Поиск по названию, фильтр по категории и диапазону цен
- Сортировка по цене (возрастание/убывание) и по алфавиту
- Кнопка сброса всех фильтров
- Отдельная страница товара с подробным описанием

**Авторизация и роли**
- Регистрация и вход по email/паролю
- Валидация пароля (минимальная длина, наличие букв и цифр)
- JWT access и refresh токены, хранение сессии между перезагрузками
- **Ролевая модель:** разделение на `user` и `admin`. Защита приватных маршрутов (возврат `403 Forbidden` при недостатке прав).

**Личный кабинет**
- Просмотр email и даты регистрации
- Смена email и пароля (со сверкой текущего пароля)
- История оформленных заказов с актуальными статусами

**Корзина и заказы**
- Добавление/удаление товаров, изменение количества
- Оформление заказа как авторизованным, так и гостевым пользователем
- Хранение данных заказа (ФИО, телефон, email, адрес) и его позиций

**Избранное**
- Добавление/удаление товаров в избранное (только для авторизованных)
- Отдельная страница со списком избранных товаров

**Админ-панель** *(доступна только пользователям с ролью `admin`)*
- **Управление заказами:** просмотр списка *всех* заказов в системе (не только своих). Изменение статуса заказа (Оформляем, Собираем, Доставляем, Готов к получению) через выпадающий список с мгновенным обновлением интерфейса.
- **Управление товарами:** полный CRUD (создание, частичное редактирование, удаление) товаров через модальные окна.
- *Архитектурная особенность:* удаление товара из каталога не ломает отображение старых заказов, так как `OrderItem` хранит снимок данных (`product_name`, `price`) на момент покупки.
- **Интерфейс:** отдельная защищённая страница `/admin` с вкладками. Ссылка на панель динамически отображается в шапке сайта только при `user.role === 'admin'`.

## Запуск проекта

### Backend

```bash
cd backend
python -m venv venv
venv\Scripts\activate       # Windows
# source venv/bin/activate  # macOS/Linux

pip install -r requirements.txt
```

Создайте файл `.env` в папке `backend` по образцу `.env.example` и укажите
`SECRET_KEY` (например, сгенерировав его командой):

```bash
python -c "import secrets; print(secrets.token_urlsafe(32))"
```

Запуск сервера:

```bash
uvicorn app.main:app --reload
```

Backend будет доступен на `http://localhost:8000`, документация API —
на `http://localhost:8000/docs`.

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Frontend будет доступен на `http://localhost:3000`.

```
│   └── app/
│       ├── main.py             — точка входа, эндпоинты публичных товаров
│       ├── auth.py             — регистрация, логин, refresh, профиль, get_current_admin
│       ├── orders.py           — оформление заказов и админские эндпоинты заказов
│       ├── admin_products.py   — CRUD-эндпоинты управления товарами для админа
│       ├── favorites.py        — избранное
│       ├── models.py           — модели БД (добавлено поле role в User)
│       ├── schemas.py          — схемы валидации Pydantic (добавлены ProductCreate/Update, OrderStatusUpdate)
│       ├── security.py         — хеширование паролей, JWT
│       └── config.py           — конфигурация из переменных окружения
└── frontend/
    └── src/
        ├── App/                — корневой компонент, маршрутизация
        ├── Entities/           — сущности и работа с API
        │   ├── user/           — типы User (добавлено role), authApi
        │   ├── product/        — типы Product, adminProductApi (CRUD товаров)
        │   └── order/          — типы Order, adminOrderApi (получение всех заказов, смена статуса)
        ├── Widgets/            — переиспользуемые блоки (Header с условным рендерингом ссылки на админку)
        └── Pages/              — страницы
            ├── ProfilePage/    — профиль пользователя
            └── AdminPage/      — защищенная админ-панель с вкладками "Заказы" и "Товары" (AdminPage.tsx, AdminPage.css)
```
